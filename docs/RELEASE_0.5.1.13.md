## English

Sift Uninstaller 0.5.1.13 is a documentation/packaging development update. The English-first, Turkish-second README now includes a direct Windows setup download, dependency-free installation guidance, checksum guidance and clear unsigned-release/testing limitations. Application behavior is unchanged from 0.5.1.12; the displayed and packaged version is incremented.

Download `Sift.Uninstaller-Setup-0.5.1.13.exe` from Assets; “Source code” archives are not installers. Windows 10/11 x64; Node.js is not required. Use the accompanying `SHA256SUMS-0.5.1.13.txt` to check file integrity. This installer is unsigned. Real installer/UAC/upgrade and real program-removal testing remain pending. Existing security, recovery and cleanup limitations still apply; see the README and docs/VERIFICATION.md.

Type checks, 59 regression tests, the NSIS build and the isolated packaged-Electron smoke check passed locally on Windows on 2026-10-09. No real installed program or user data was removed.
