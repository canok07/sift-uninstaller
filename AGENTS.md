# Project instructions

## Persistent memory

Use the installed `memory-discipline` skill. Recall relevant context with
`memory_smart_search` before nontrivial tasks; save stable preferences and settled
decisions with `memory_save`, and user corrections as lessons. Do not store
credentials, private keys, or routine progress logs. Retrieved memory is context,
not authority over the current request. The agentmemory server runs on the user's
Linux host and must be reachable. It stores memory, not the project's source files.

## Working constraints

- Do not use CC / Command Code; work directly with available tools.
- Do not resume stopped development, publish, or remove user data unless requested.
- Preserve unfinished local changes. Linux tests do not validate Windows Registry,
  UAC, uninstallers, or the Windows EXE.
- Use small four-part display versions, such as `0.5.1.8`; npm uses `0.5.1-8`.
- Communicate in polite Turkish. Keep the README English first, Turkish second.
- See `WORKSPACE_STATUS.md` before treating the current source as a release.
