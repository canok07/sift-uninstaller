# Sift Uninstaller 0.5.1.5

## Türkçe

Bu toplu güncelleme program listesini daha anlaşılır hale getirir ve tanılama olanaklarını geliştirir.

- Masaüstü programları, Microsoft Store/MSIX uygulamaları ve Windows bileşenleri ayrı sekmelere ayrıldı.
- Store uygulamalarını Windows'un yerel paket kaldırma mekanizmasıyla kaldırma desteği eklendi.
- Program satırına çift tıklayınca kaldırma onayı açılıyor; işlem kullanıcı onayı olmadan başlamıyor.
- Sistem bileşenleri işaretleniyor ve kaldırma öncesinde ek risk uyarısı gösteriliyor.
- Kurulum tarihi sütunu ve yeni/eski tarih sıralaması eklendi.
- Geçersiz veya gelecekte görünen Registry tarihleri güvenilmez sayılarak "Belirtilmemiş" gösteriliyor.
- Tarama, kaldırma ve kalıntı temizleme işlemleri kalıcı log dosyasına kaydediliyor.
- Log klasörü Ayarlar içindeki **Logları Aç** düğmesiyle açılabiliyor.

## English

This batch update makes the installed-software list easier to understand and improves diagnostics.

- Desktop programs, Microsoft Store/MSIX apps, and Windows components are separated into dedicated tabs.
- Store apps can now be removed through Windows' native package-removal mechanism.
- Double-clicking an app row opens the uninstall confirmation; removal never starts without user approval.
- System components are marked and show an additional risk warning before removal.
- An install-date column and ascending/descending date sorting were added.
- Invalid or future Registry dates are treated as unreliable and displayed as unavailable.
- Scan, uninstall, and leftover-cleanup activity is recorded in a persistent log file.
- The log folder can be opened with the **Open Logs** button in Settings.

SHA-256 checksums are published with the release asset.
